# 实现前独立验收预期

固定于2026-10-11，先于S5.1代码；业务数值来自既有人工清单，不从Agent响应反推。

1. 录入角色：真实模型选择 get_ingestion_result 或 process_document，真实工具返回现存 document_id/状态；不得请求路径/上传/Cypher。复用成功资料不能重新解析抽取。
2. 知识角色：真实模型选择 graph_lookup，现有原件范围应有2构件；范围内观测仍为3条、面积0.04/2.6/0.9m²、日期未知、synthetic。首轮任务只读构件，不以模型收尾判断数值正确。
3. 原文证据：范围内引用可打开；另一文档/桥梁/不可见记录引用拒绝；未知日期过滤、confirmed_only、include_synthetic=false同样约束证据读取。
4. 权限：录入不能生成报告；知识不能处理PDF；模型参数role/scope/path/Cypher不能提升权限。相同非法查询从HTTP/Agent均由原用例拒绝；无范围知识请求在调用模型前拒绝。
5. 循环：重复调用/超限/非法JSON/重复JSON键/未知字段/并行批次/截断输出/传输错误可定位，不自动网络重试；工具错误有request_id/耗时记录。首次失败原样留存。
6. 问答仍经S3.3有限断言与引用核验；报告仍经S4.1确定性生成。自由收尾不能作为已核验业务答案。工具返回不伪造专业审核通过。
7. 网页实际操作：重复上传已有PDF→查看状态→精确查询→已核验问答→创建/读取报告→打开证据→下载Markdown；分别记录实际服务/模型/图、浏览器结果。只做S5.1新入口验证，不重新运行旧实验。
8. 浅色/深色/窄窗口能看到状态、引用与错误，模型/原文HTML作为纯文本；写入期间禁用提交，读取轮询有上限/可停止；失败后不展示上次成功结果。
9. 旧tracked证据文件字节不变；业务图/来源/索引不因本步读取而改变，新报告/Agent日志单独保存；本地指针有效。
