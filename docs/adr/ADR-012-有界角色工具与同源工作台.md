# ADR-012 有界角色工具与同源工作台

- 状态：已接受
- 记录日期：2026-10-11
- 决定依据：用户授权S5.1先定接入再实现；根spec既有角色/权限/8步默认下的实施选择，非逐项用户技术批准
- 适用范围：S5.1 Agent入口、工具范围与网页
- 替代关系：无；沿用ADR-001/009/010

## 背景

S2–S4共享用例已实现，需要真实模型工具调度和完整网页操作，同时保留范围、有限断言与确定性报告边界。

## 决定与理由

沿用已配置中转的原生function tools，建立有界串行循环，不加入新框架；两条固定角色HTTP入口注入权限/上下文，不接受模型role/scope覆盖。知识工具补充answer_question调用已核验用例；模型自由收尾仅在响应trace留存，不呈现为业务答案。工具错误、重复及超限终止，不隐式重试。资料/报告长任务仍由原runner执行。

前端沿用FastAPI同源静态HTML/JS/CSS和既有PDF.js查看器，避免新增构建/运行依赖。报告呈现结构化行和可信应用引用；原文及模型输出用textContent，不渲染原始HTML。

## 影响与边界

本机单用户、服务器配置actor；不是任意自主规划或多用户授权系统。原文证据工具保守限定为有当前可见已接纳记录的引用，独立说明仍通过语义/核验问答工具使用。真实中转工具能力必须单独运行验证；不推论持续稳定性、专业审核或业务准确率。
