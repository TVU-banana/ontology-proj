# ADR-002 业务事实与证据分离

- 状态：已接受
- 记录日期：2026-10-11（已认可契约补录；不追认原决定日期）
- 决定依据：用户认可的最小业务契约；语义修订 1.1 的三类规则已逐项确认，来源见契约 §8.1
- 适用范围：文档解析、业务抽取、校验、固定图映射
- 替代关系：无

## 背景
DoclingDocument 描述文档结构和原文位置，不能直接作为桥梁业务事实。模型候选还可能包含未知、否定、错误关联或缺项，结构合法不等于事实有效。

## 决定与理由
流程分为原生解析、统一文档、业务候选、程序校验与记录生成、固定图映射。业务记录采用 Bridge、Component、Defect、Observation、Evidence，测量并入 Observation；原文与位置保留供回查。模型提出候选，程序核验身份、单位、引用及语义并决定分流，不让模型任意决定图结构。

## 影响与边界
保留原文分类与未知值，不能把否定/疑似陈述直接变成肯定病害事实，也不能按报告年份补观测日期。字段、局部位置规范和上下文证据规则只在契约维护，本记录不复制枚举或映射。载荷结构版本、语义修订与实验配置版本分别追踪。
