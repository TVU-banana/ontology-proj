# ADR-010 确定性汇总报告

- 状态：已接受
- 记录日期：2026-10-11
- 决定依据：本轮用户明确选择程序生成固定汇总、仅接受结构化范围；继承 PRD §7 与 S4.1 保存/登记要求。
- 适用范围：S4.1 病害与观测汇总；不改变 S3.3 模型问答。
- 替代关系：无；细化根 spec §13 的报告生成默认。

## 背景

报告本阶段是固定字段、原值与引用汇总。模型输出增加字段遗漏与核验负担，自由文字重点解释尚未定案。

## 决定与理由

用程序从许可范围的当前已接纳记录组装 ReportData，逐字段/原句检查后固定模板渲染。非空自由要求明确拒绝；不新增模型调用。原文说明可复用已登记片段，无需向量检索/索引重建。专业审核仅 not_run。生成 JSON 的端口由确定性用例承担，不将此能力描述成自主 Agent。

文件先保存并校验摘要，随后 Report/CITES/Operation 成功/AuditEvent 图事务登记。登记失败可显式复用文件重试；未完成重启任务显示 interrupted，不自动生成。已发布快照不可改写，查看时暴露当前引用状态变化。

## 影响与边界

得到可重复核验的固定汇总，承担严格字段证据与有限字段核验的边界。未实现自由要求理解、自动冲突识别、评级/原因/处治、专业审核或复杂真实资料验收。S5 Agent/完整网页和稳定性仍另行验证。
