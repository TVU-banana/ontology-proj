# ADR-009 核验断言后呈现答案

- 状态：已接受
- 记录日期：2026-10-11
- 决定依据：根 spec §13.1–13.2 的可比较断言与引用边界，用户授权执行 S3.3 后的实施选择；不表示逐项批准所有实现细节。
- 适用范围：首版知识问答、生成提案、答案校验与呈现。
- 替代关系：无；落实 ADR-001、002、003、008。

## 背景

有效 Evidence ID 只能证明引用存在，不能证明自由生成的一段话被引用支持。首版既缺通用语义蕴含校验，也不应拿另一次模型判断当作事实核验。

## 决定与理由

模型选择字段、引用与拒答原因，程序逐项核对许可范围、当前接纳、引用与记录配对、关键值及单位，然后用模板/原句生成 Claim.text。原文说明逐字呈现，不转为观测；面积自动呈现原记录的近似性、断言与统计范围。生成后再次读记录/引用，期间撤销接纳或字段变化则整份拒绝。

这是能明确验证的首版输出边界。模板限制自由措辞，但不会把 ID 正确误当成语义正确；以后放开自由文本或派生指标须新增可核验契约与预期。

## 影响与边界

使用真实生成模型选择证据并形成提案，最终表述可核查；不宣称是自主 Agent。summary 仅为已核验字段的列表总结，不新增工程评价或派生数值。暂不自动检测跨文档冲突；不能证明冲突时拒绝生成冲突结论。每个问题保存独立日志，错误不覆盖首轮，不污染业务图。

## 规范与验证入口

[Spec 005](../../specs/005-cited-answer/spec.md)、[验收](../../specs/005-cited-answer/results/review.md)。实际证据限于受控合成问题、当前中转服务及隔离状态测试；自由表达/专业判断/通用复杂资料尚未证明。
