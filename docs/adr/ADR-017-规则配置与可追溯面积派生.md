# ADR-017 规则配置与可追溯面积派生

- 状态：已接受
- 记录日期：2026-10-13
- 决定依据：用户明确采纳统一规则、单位兼容、明确尺寸推算、证据验证与成组反例方案并授权实现。
- 适用范围：业务面积抽取/校验、图标量、查询、问答与固定报告；不涉及OCR或登记来源泛化。
- 替代关系：无；细化ADR-002/009/010/015。旧规则实验和稳定性证据不追认新版通过。

## 决定与理由

单位/术语别名与有限表达元数据集中在带版本的business-rules.json。模型理解来源中的说法并提议字段，程序核查原文/对象范围并以Decimal计算；不因模型的JSON结构合法就放行。借鉴社区模型与规则组合、量纲检查和行为变形测试，但MVP不引入通用规则平台或新NLP依赖。

新增0.3载荷保留直接与派生面积区别；派生记录原表达、输入、原单位、因子、方法与版本。明确矩形长宽或明示面积乘积才求值，范围/最大尺寸/不规则/缺单位/冲突不猜。新的规范面积必须能复算，表达证据必须完整；无原始标量仍保持null。图中派生对象以JSON字符串存储、读取解码，不创建Measurement节点。

旧0.1/0.2保持原规则与读取兼容；新模型请求固定0.3并传服务器identity_mode，registered仍有原来源绑定。配置/提示/Schema的摘要进入抽取配置，不覆写旧DATA_ROOT快照或旧baseline。报告模板1.2显示派生来源，旧Markdown不重新渲染。专业审核仍not_run；UI仅功能标识，不做样式优化。
