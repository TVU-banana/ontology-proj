# ADR-019：OCR 引擎与推理后端

- 日期：2026-10-13
- 状态：已接受
- 依据：用户明确确定 RapidOCR、ONNX Runtime、PP-OCR，并随后授权完整落地。

## 决定与理由

复用 Docling 的 RapidOCR 适配器，以 ONNX Runtime 执行 PP-OCR 模型，不另开发识别算法。固定引擎，避免环境自动选型改变结果。首轮资源基线采用当前锁版本 RapidOCR 3.10.0 包内的 PP-OCRv6 small 检测/识别及配套方向分类权重；具体规格为实施基线，规格效果与部署证据以阶段结果为准。

## 影响与边界

自动采用Docling PDF感知区域判断；picture/chart及原生文字覆盖且无位图的区域跳过；支持关闭和指定物理页FULL_PAGE强制。使用项目内适配pipeline/模型子类，不注册外部插件或修改SDK全局。模型与后端固定、本地预检、禁止隐式下载；空识别或错误不发布完整结果。诊断单独保存，原生JSON和旧快照不改。坏文字层/原生文字与轮廓字混合不自动质量猜测；路由存在版面漏判边界，不承诺通用扫描质量。历史快照和原验收边界保留。
