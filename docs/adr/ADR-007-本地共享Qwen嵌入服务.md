# ADR-007 本地共享 Qwen 嵌入服务

- 状态：已接受
- 记录日期：2026-10-11
- 决定依据：用户选择下载开源小模型，确认中文为主、夹杂英文和技术文档，明确授权部署 Qwen3 Embedding 0.6B；运行时为本轮实施选择。
- 适用范围：S3.2 前置嵌入服务及多个本机项目共享调用。
- 替代关系：无。

## 背景

已有中转模型列表未提供可识别嵌入候选；抽取生成模型不能冒充已验证的嵌入模型。用户希望减少云端逐次调用费用，并复用于其他项目。当前机器为 M4 / 24 GB。

## 决定与理由

采用 Qwen3 Embedding 0.6B，原生 Ollama 提供本地 API。该规模兼顾资源成本与中文、英文、技术资料的跨项目用途；官方支持多语言、较长输入及查询任务指令，Apache-2.0 许可。BGE-small 更轻量但偏中文短文本；BGE-M3 和 pplx-embed 是有价值的对照，不认定 Qwen 在所有数据上最优。

采用 Ollama 仓库 Q8_0 版本，以便原生 Metal 推理、模型管理和 API 复用；量化不等于原始精度，需要独立验证。服务由用户 LaunchAgent 管理，仅绑定回环且关闭云端功能；权重独立于业务 DATA_ROOT。具体版本、摘要、接口及生命周期以 [部署说明](../../deploy/embedding/README.md) 为主要维护位置。

## 影响与边界

无云端嵌入逐次费用，但仍有下载、磁盘、内存、计算和维护成本。多个项目共享模型服务，各自维护数据与索引，不共享业务权限或向量空间治理。更换模型内容、指令或维度必须显式处理索引重建。

部署授权只恢复模型服务前置工作，不自动授权全部 S3.2 实现。实际小样例通过不等于模型 A/B 胜出或复杂语料验收；未来效果/资源证据若动摇选择，再新增替代决策。
