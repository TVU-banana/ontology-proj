# ADR-013 S5.2 系统稳定性证据边界

- 状态：已接受
- 记录日期：2026-10-12
- 决定依据：用户确认保留完整验收门槛；经解释60分钟/120轮、报告/重启/故障标准与现有中转synthetic调用范围后明确“继续执行”。
- 适用范围：S5.2新系统级验证及交付评价。
- 替代关系：无；不替代旧抽取稳定性门槛。

## 背景

S5.1仅完成本机synthetic网页和两角色工具链路，不能证明持续稳定性、复杂真实资料或专业验收。旧DATA_ROOT/图需保护，新增试验不能与旧图写入混用。

## 决定与理由

采用独立图/卷/DATA_ROOT的新系统试验；冻结时长、次数、独立预期与首次通过门槛，再收集实际证据。复用旧已验收发布结果作为fixture，避免重跑旧解析/抽取实验。正常采样、预定故障、真实provider任务分别判定，首次失败保留，不靠补跑覆盖。

## 影响与边界

结果只覆盖实际本机版本、载荷与时长，不是生产可靠性指标。完整PRD/spec Done维持，真实复杂素材、专业人工及真实历史边界仍单列。新provider仅已确认的既有中转与synthetic范围；密钥不交付。accepted只表示决定获准，不表示试验已通过。
