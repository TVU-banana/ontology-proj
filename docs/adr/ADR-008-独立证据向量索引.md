# ADR-008 独立证据向量索引

- 状态：已接受
- 记录日期：2026-10-11
- 决定依据：根 spec §9.4–10 的既有设计与 S3.2 授权下的实施细化；不是用户逐项批准。
- 适用范围：S3.2 的切块、索引发布、语义检索和受控上下文。
- 替代关系：无；落实 ADR-002、003、007。

## 背景

业务图已可精确查询；嵌入失败不应重跑解析/抽取，也不应让已发布业务数据失去可用性。解析块的语义与审核状态不同，直接整段索引会混入待复核观测或丢失否定含义。

## 决定与理由

索引显式独立执行，维护自己的运行 token 与 running/ready/failed 状态；片段、来源 Evidence、完成状态和审计在单事务中发布。相同 profile 的已完成文档复用；失败/中断须显式重试，不自动调用模型。向量不参与业务接纳。

从已校验记录引用与 statements 构造片段，一个业务片段只对应一个接纳记录；说明/否定保留来源类别。查询时再检查当前归属、接纳及来源关系状态。原文跨度独立保存，字段名称只是嵌入上下文。全库固定单一模型/切块 profile，变化明确拒绝，避免混合空间。

上下文先取精确事实，再按语义排名和完整项预算取舍；输出分栏不改变排名。这样否定原文不会因业务片段分组优先而被挤掉。

## 影响与边界

独立索引接口可恢复和复用，不自动跟随旧 process。现阶段只索引已保存记录/说明引用，其他未选择块列入排除诊断。全局候选池有上限，过滤后允许不足 top_k；更换 profile 需要另行设计显式重建，不提供自动迁移接口。说明未人工审核，confirmed_only 不返回它们。
