# ADR-005 S2.2 独立稳定性与结果发布

- 状态：已接受
- 记录日期：2026-10-11
- 决定依据：用户授权执行 S2.2，并明确确认五份素材各两次、首次结果 10/10 的门槛
- 适用范围：应用抽取、语义 1.1、业务产物发布与独立验收
- 替代关系：无；不覆盖原实验 1.0 或 ADR-003/004

## 决定与理由

五份固定素材各独立调用两次，固定 Schema、语义 1.1、模型和参数；首次结果必须 10/10 通过事实/语义/证据核验。不自动重试、不带前轮反馈、不以修正成功抵消首次失败。新预期先于请求冻结，旧 golden 和原实验结果保持原样。

每次应用抽取先保存请求、响应、候选与诊断，只有结构/语义/记录检查通过才发布业务产物。缺面积允许契约约定的 pending_review，失败整包不产生可用 records。独立事实验收是阶段门槛，运行用例不读取 golden，不能把程序校验通过等同于模型事实完整。

业务运行记录使用文档下独立 business-runs 目录，业务发布摘要与 S2.1 的解析 manifest 分开；本地解析恢复不扫描业务运行。这避免用解析成功/状态替代抽取成功，正式图/操作登记仍在 S2.3 接通。

## 边界与规范入口

没有图写入、Agent、问答或报告功能；单进程共享用例。跨进程 runner、正式图状态及逐对象恢复未实现。技术和任务细节见 [Spec 002 plan §9](../../specs/002-ingestion-foundation/plan.md#9-s22-业务抽取与独立稳定性详细计划)、[任务](../../specs/002-ingestion-foundation/tasks.md)。接受决定不代表实现或验收已通过。
