# ADR-003 独立预期与验收证据保护

- 状态：已接受
- 记录日期：2026-10-11（既有验证流程补录；不追认原决定日期）
- 决定依据：用户确认核心事实基线，并授权先固定预期、制作变体、解析检查、固定配置独立抽取和事实对照的流程
- 适用范围：synthetic 素材、解析/抽取实验、回归与验收
- 替代关系：无

## 背景
抽取结果若反过来成为预期，或修正成功覆盖首次失败，就无法判断真实稳定性。演示材料还可能被误解为真实检测证据。

## 决定与理由
先固定独立预期，再制作素材；预期不给抽取模型，应用运行时不能读取预期补齐事实。先核查解析保留的内容和位置，再在固定配置下独立抽取。首次响应、候选、诊断及事实对照独立保留；修正实验和新规则基线另存，以便区分解析问题、模型问题与校验边界。

## 影响与边界
synthetic/演示来源、未知日期和否定原文必须保留。规则改变需说明版本与新预期依据，不能改旧结果使其通过。合成样本验证不等于复杂真实 PDF、OCR、真实历史检测或数据库验收；稳定性门槛另在相关任务定案。
