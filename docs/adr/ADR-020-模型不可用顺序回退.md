# ADR-020 模型不可用顺序回退

- 状态：已接受
- 记录日期：2026-10-16
- 决定依据：用户要求修复 Deepseek v4.1 Flash 不可用时不能顺延的问题，并指定备用模型 glm-5.3-flash。
- 适用范围：共享中转的抽取、问答、Agent 及模型就绪检查
- 替代关系：无；补充运行期可用性策略，旧实验首次调用证据不迁写。

## 背景
原适配器仅发送一次请求，主模型不可用即终止；就绪检查只认可主模型。

## 决定与理由
在同一中转地址和凭据下使用显式有序备用模型链，每模型最多一次。仅可用性故障触发，不通过换模型修复业务校验失败。默认备用采用用户指定 ID，可显式清空关闭。共享传输复用策略，避免抽取与问答、Agent 行为不同；不重放已经执行的工具。

## 影响与边界
保留每次脱敏尝试、原提供方模型名与最后请求模型，配置链参与抽取指纹。耗时和费用可能增加，尤其超时不能证明上游没有执行。模型列表就绪不等于生成验收。旧稳定性实验仍保留固定单模型首次调用口径。

## 规范与验证入口
主要行为见 [spec §16.2](../../spec.md#162-重试边界)；离线回归见 [test_model_fallback.py](../../tests/unit/test_model_fallback.py)。本轮不宣称真实中转故障切换或备用模型输出质量已经验收。
