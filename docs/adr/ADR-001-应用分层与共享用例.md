# ADR-001 应用分层与共享用例

- 状态：已接受
- 记录日期：2026-10-11（既有设计补录；不追认原决定日期）
- 决定依据：根 spec 的既有设计与 Spec 002 的实施默认，不表示用户逐项批准所有技术选型
- 适用范围：应用组织、HTTP/Agent 入口、外部适配器
- 替代关系：无

## 背景
同一录入、查询与报告流程需要被 HTTP 和后续 Agent 调用；解析、模型与数据库的工具格式不能成为业务规则的运行依赖。

## 决定与理由
核心规则接收普通数据；application 组织用例并通过端口调用外部能力；adapters 封装 Docling、模型、文件及 Neo4j；HTTP 和 Agent 调用同一套用例。bootstrap 负责配置与组装。这样可以分别验证规则、流程和外部服务，避免入口各自维护不同规则。

## 影响与边界
增加必要的端口和数据转换，但只随当前节点建立实际需要的模块，不预建全部接口。应用本机运行是用户已确认选择；Python/FastAPI 属既有实施默认。单进程等具体运行约定以计划为准，不在本记录复制。替身检查不能证明真实服务可用。
