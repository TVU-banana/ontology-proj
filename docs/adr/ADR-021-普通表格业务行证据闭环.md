# ADR-021 普通表格业务行证据闭环

- 状态：已接受
- 日期：2026-10-16
- 依据：用户在系统筛查后授权修复业务实例提炼；具体行证据规则为该授权范围内的实施选择。
- 范围：0.4/catalog普通报告抽取；原registered与显式编号路径保留。
- 替代关系：补充ADR-018的普通表格关系证据路径；替代其“无桥原编号只允许同一quote桥名+构件编号”的限定，其他桥身份及历史记录规则继续有效。

## 背景

两份简单PDF解析正确，但业务候选因构件/部位粒度混淆、无观测原编号行校验及跨单元格关系证据不兼容被拒绝。仅换模型或取消校验无法解决契约不一致。

## 决定与理由

同原构件编号一个构件，病害位置承载部位。编号本身可作为缺独立名称时的原文显示名称，类型不推断。无观测编号可用明确构件编号列与唯一普通行的字段证据确认归属；桥关系结合已解决的报告绑定及两端原文引用。每个quote仍独立连续，程序不拼接假原文。候选及正式记录均校验行和父对象。

保持结构版本0.4、提升catalog语义至1.5和配置指纹；记录字段无变化，既有发布不迁写。structure传递为辅助解析信息，不作为照片诊断或自动业务关系依据。

## 边界

不扩展无原编号构件、病害枚举、跨报告融合、多事实单元格或跨页表格。错误输出仍拒绝，不自动改候选为通过；实际模型验证与人工构造离线候选明确区分。
