# ADR-014 真实验收请求表示与不可信来源隔离

- 状态：已接受
- 记录日期：2026-10-12
- 决定依据：用户批准指定API真实验收后，在既有实施授权/证据契约下的执行器选择；用户没有逐项批准编码字段
- 适用范围：胜利大桥S5.2本轮定制执行器；不作为默认生产适配器行为
- 替代关系：无；不替代ADR-002/003/013

## 背景

原全文报文重复携带大量native table对象、坐标和长来源ID，并包含已知不可用单元格。原件/首次解析必须保留，不能靠golden补值或缩为三条观测来放行。

## 决定与理由

阶段执行器保留全部块text/original_text、顺序/页码及行列/跨度/原生表头；表内容通过块仅发送一次，表摘要保留ID/页/行列数，重复grid/bbox不发送。模型来源使用短ID双射，原始响应原样保留，只还原source.block_id，不改变业务值，再交原有权威校验。

已知不可用源保持原文并附明确风险标记；候选引用该源拒绝整包。未验证表头/跨页关系不推断，不把警告当作修复。实际费用/模型输入输出上限不能由字符数或接口兼容性猜测。

## 影响与边界

获得可核查的完整文字输入/较小报文及风险隔离，增加阶段特有ID编码/来源还原。默认RelayFactExtractor未修改；本次不能声称默认产品已支持真实全报告或通用质量门。首次调用可能截断或被校验拒绝，仍须保存。后续新预算/请求必须新冻结；不能降低完整S5.2要求。

## 规范与验证入口

业务来源和证据约束仍见[spec §6](../../spec.md#6-文档与来源数据契约)、[§7](../../spec.md#7-业务数据契约)；阶段表示及失败停止规则见[执行基线](../../specs/008-system-acceptance/results/real-shengli-20261012-01/execution.md)，结果见[验收记录](../../specs/008-system-acceptance/results/real-shengli-20261012-01/review.md)。已接受不是已通过真实三模块验收。
