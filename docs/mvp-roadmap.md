# MVP 落地清单

版本：1.0；更新：2026-10-11。本文件是 MVP 构建的线性主线，供用户和 Agent 按同一顺序推进。

**当前下一节点：S3.1，细化精确/关系查询和最小证据查看器。** S1.1/S1.2、S2.1–S2.3 已完成；[S2.3 验收](../specs/002-ingestion-foundation/results/s2.3/review.md)有实际 HTTP → Docling → AI → Neo4j、事务和恢复证据。S2.2 最新固定抽取基线 1.1.4 独立首次 10/10，见 [复验](../specs/002-ingestion-foundation/results/s2.2/stability-followup.md)，历史失败保留。详细顺序见[计划](../specs/002-ingestion-foundation/plan.md)与[任务](../specs/002-ingestion-foundation/tasks.md)。不将受控素材成功视为复杂真实报告通用能力。

## 使用规则与最终目标

- 从上到下推进，沿用 S0–S5 阶段编号；细分步骤使用固定编号，例如 S2.1。后续计划、任务与运行证据均引用这个编号。
- `[x]` 表示该步在写明的范围内已有完成证据；`[ ]` 表示未完成。进入某步时才拆详细任务，有结果后再勾选。当前节点、实际结果和阻塞项见[交接](../.handoff/latest.md)。
- 每步写明前置、工作、产物和完成条件。需要作出的技术选择放在相应步骤，未确定的选择不能写成已实现。
- [PRD](../PRD.md)维护产品范围，[spec](../spec.md)维护总体设计，[业务契约](../specs/001-business-extraction/contract.md)维护字段与语义；本页维护顺序和完成条件，不复制完整契约。

最终用户能够上传演示 PDF，查看处理状态与业务记录，提出问题并回查引用，生成一种固定的“病害与观测汇总”。重复上传不产生重复数据，重启后结果仍在，失败可检查。三个业务模块仍是资料录入、知识问答、可追溯报告生成。

  **产物：** 可重复运行的文件/解析用例、持久化来源草稿及解析结果、完整性摘要和阶段错误记录；[plan §8](../specs/002-ingestion-foundation/plan.md#8-s21-文件来源草稿与解析详细计划) 与 [tasks](../specs/002-ingestion-foundation/tasks.md) 已细化；[T01](../specs/002-ingestion-foundation/results/s2.1/t01-review.md)/[T02](../specs/002-ingestion-foundation/results/s2.1/t02-review.md) 已完成；[T03 统一文档](../specs/002-ingestion-foundation/results/s2.1/t03-review.md) 离线回归通过；[T04 本地管线](../specs/002-ingestion-foundation/results/s2.1/t04-review.md) 发布/恢复检查通过；[T05 CLI](../specs/002-ingestion-foundation/results/s2.1/t05-review.md) 参数/错误与 HTTP 回归通过；真实转换验收现已完成，见下方 T06 证据。

  **完成条件：** 当前两页 PDF 经应用命令行保存并实际解析，产物和位置可核查，重复/冲突/失败及重启读取有证据；本地完成不表示正式图登记或 API 录入成功。独立预期只在验收端读取，不用于运行补齐事实。

  **完成证据：** [T06 / P01–P06 验收](../specs/002-ingestion-foundation/results/s2.1/review.md)：109 项测试、27 项真实 CLI/解析检查、2 页几何与 72 框的 agent 检视通过。T01–T06 完成；旧首次失败保留，用户逐页验收、复杂真实报告/OCR 和正式图登记未验证。

  **架构要点：** DoclingDocument 是文档结构，业务 Schema 是抽取目标，两者通过适配和抽取连接，不能直接等同。

- [x] **S2.2 接通模型候选、证据校验和业务记录生成。**

  **前置：** S2.1、业务契约及语义修订 1.1。

  **工作：** 迁入抽取调用与纯规则；实现说明分类、桥头位置规范和组件上下文证据规则。保留未知值、否定、疑似及来源性质，保存候选和诊断。

  **产物：** 抽取/校验用例、业务运行与 Evidence、待审核/拒绝结果、离线正反例证据已落地；[完成验收](../specs/002-ingestion-foundation/results/s2.2/stability-followup.md)记录 133 项测试、最新 10/10、实际读取/复用及前四轮失败保留。

  **完成条件：** 程序按契约分流；通过、缺项与失败可区分；原文证据可核查。落实语义 1.1，五份各独立两次首次事实/语义/证据验收必须 10/10；修正另记，不能抵消首次失败。最新基线已达到，旧失败保持原样。

  **架构要点：** 模型提出候选，程序验证与决定写入。语义 1.1 的契约定稿不等于程序已经实现，也不改变旧实验结果。

- [x] **S2.3 接入 Neo4j，形成可查询、可恢复的录入闭环。**

  **前置：** S2.2 的记录与证据；本步定案 Neo4j 版本/部署并实际探测。

  **工作：** 建立唯一约束、固定图映射、事务提交和查询；核验本地草稿后建立正式来源/操作登记，接通串行 runner 与上传/处理/状态/结果 API。实现文件去重、重启恢复、失败状态和操作记录。

  **产物：** 启动/约束脚本、图存储适配器、录入 API、实际查询与可靠性证据。

  **完成条件：** 上传后可查询桥梁、构件、病害、观测及来源；重复上传不重复解析/抽取/建图；重启数据仍在；写入失败不留下半包业务数据，候选与诊断保留。

  **架构要点：** 图结构由固定映射决定，模型不执行任意 Cypher；模型调用不能放进会重试的图事务回调。待审核与已发布记录的查询边界明确。

  **完成证据：** [S2.3 验收](../specs/002-ingestion-foundation/results/s2.3/review.md)：158 项测试、原件/缺面积两条真实链路、进程中断与数据库/应用重启通过；默认查询排除 pending。仅后端录入与受控图查询，不表示 S3 网页/问答已完成。

## S3：完成检索、证据回查和问答

S3.1 实施入口：[Spec 003](../specs/003-query-evidence/spec.md)、[plan](../specs/003-query-evidence/plan.md)、[tasks](../specs/003-query-evidence/tasks.md)。

- [x] **S3.1 实现精确/关系查询和最小证据查看器。**

  **前置：** S2.3 中真实可查询的图与来源文件。

  **工作：** 按桥梁、构件、日期和状态查询；通过 Evidence ID 打开 PDF，定位页面/区域及命中文字。

  **产物：** 查询用例/API、代表性查询结果、PDF 查看页与位置核查证据。

  **完成条件：** 对象、面积和关系查询正确；未知日期不进入限定日期结果；点击引用可回到对应原文，不重新向量搜索“猜”来源。

  **完成证据：** [S3.1 验收](../specs/003-query-evidence/results/review.md)：175 项离线、2 项实际图机制测试、56 项实际 TCP 检查和浏览器两页/缩放/旋转/主题/小窗口核查通过；0 新模型生成。真实跨期病害身份和用户专业人工验收仍未证明。

- [x] **S3.2 实现语义检索与受控上下文。**

  **前置：** S3.1；本步选择并探测嵌入模型及 Neo4j 向量能力。

  **工作：** 对有效原文切块/嵌入，建立向量索引、范围过滤及 ContextBundle；区分结构化事实与原文说明。

  **产物：** 嵌入/检索适配器、索引与查询证据、限定范围的上下文样例。

  **完成条件：** 实际索引写入与检索可用，维度/范围匹配；语义检索不代替编号/日期精确查询；索引失败不会把已有图记录伪装成全部不可用或全部成功。

  **完成证据：** [S3.2 验收](../specs/004-semantic-context/results/s3.2/review.md)：207 项离线、实际图组合机制、151 项最终 TCP 检查通过；两份各 14 片段、69 个返回引文核验，实际重启复用和嵌入故障降级。限定小 synthetic，不代表复杂报告或问答已验收。

- [x] **S3.3 接通有引用的知识问答。**

  **前置：** S3.1–S3.2 的查询、检索和证据回查。

  **工作：** 基于受控上下文生成 Answer，检查引用；覆盖事实、关系、原文与资料不足的问题。

  **产物：** 问答用例/API、问题清单、实际答案与引用检查记录。

  **完成条件：** 对象/数值答案与记录一致，引用支持对应表述且可回查；资料不足明确说明；原文中的范围说明或否定不生成新病害。

  **完成证据：** [S3.3 验收](../specs/005-cited-answer/results/review.md)：237 离线、实际图撤回保护、六题首轮32项及最终呈现11项实际TCP检查通过；共6次真实生成，引用逐项核验，范围外不生成。字段/原句呈现的受控问答完成，自由工程结论与系统持续稳定性未证明。
